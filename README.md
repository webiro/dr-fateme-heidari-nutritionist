# وب‌سایت شخصی متخصص تغذیه

کپی‌رایت © WEBIRO. تمام حقوق این قالب و زیرساخت برای WEBIRO محفوظ است.

پروژه یک سایت شخصی RTL برای متخصص تغذیه است. هویت پزشک، لینک‌ها، رنگ‌ها، سکشن‌ها و آدرس از `config.json` خوانده می‌شود تا بتوان همان هسته را برای پزشک دیگر کلون کرد.

## صفحات
- `index.html` صفحه اصلی
- `qrcode.html` کارت دیجیتال (کنونیکال به صفحه اصلی)
- `dashboard/index.html` پنل مشاهده رزروها (ورود لازم دارد، noindex)

## پیکربندی
فایل اصلی تنظیمات: `config.json`

- اطلاعات پزشک و متن‌ها
- لینک اینستاگرام، تلگرام، بله، روبیکا، ایتا، واتساپ، تلفن
- `domain` دامنه نهایی برای اعتبارسنجی بعدی
- `workerUrl` آدرس ورکر کلادفلر
- `colors.light` و `colors.dark`
- `sections` برای نمایش یا مخفی‌کردن هر بخش
- `location` شامل عنوان، آدرس، lat و lng

محتوای مقاله سئو در `content.txt` است و نباید ایندکس شود (`robots.txt`).

## قالب‌ها
نسخه فعال ریشه پروژه است. پنج دمو در `demos/v1` تا `demos/v5` قرار دارد.

برای دیدن دمو:

`http://localhost/project/demos/v2/`

برای انتخاب قالب، `index.html` و `qrcode.html` همان نسخه را روی ریشه کپی کنید.

پوشه `demos` توسط `robots.txt` برای گوگل بسته است.

## سئو
- کنونیکال صفحه اصلی: `https://YOUR-DOMAIN/index.html`
- `sitemap.xml`
- `robots.txt`

## رزرو و بک‌اند
فرم رزرو به ورکر کلادفلر می‌رود. کد ورکر در پوشه `workers` است.

راهنمای نصب ورکر: `workers/HELP.md`

پس از ساخت ورکر، مقدار `workerUrl` را در `config.json` بگذارید. داشبورد از همان آدرس لیست و حذف را می‌گیرد.

## استقرار
با GitHub Actions فایل `.github/workflows/deploy.yml` روی GitHub Pages منتشر می‌شود. فایل `CNAME` دامنه را نگه می‌دارد.
